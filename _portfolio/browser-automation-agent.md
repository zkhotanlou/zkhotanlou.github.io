Built a production-ready browser automation agent pairing an LLM reasoning loop with Playwright to autonomously extract and act on data from evolving web pages, completing multi-step forms without manual intervention. Built a typed action-execution layer (click, scroll, fill, dropdown selection) with input validation, edge-case handling, and submission verification for reliable, repeatable automation. Exposed the pipeline via a REST API that ingested structured JSON or natural-language input, transformed it into form-ready data, and supported scheduled, unattended execution.

Tools: TypeScript, Playwright, LLM APIs, REST APIs, JSON
